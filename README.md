# Safe skyBREAK Copy — Welcome to the Game II

Copy skyBREAK text and already revealed Wi-Fi passwords in Welcome to the Game II (WTTG2).

**Скачать:** [готовые файлы 1.0.1](https://github.com/x1pee/wttg2-safe-sky-copy/releases/tag/v1.0.1).

Копирует только уже показанный текст skyBREAK: строки терминала, BSSID и результаты. Не выполняет команды и не раскрывает неизвестные пароли. Обработчики запуска и закрытия терминала не патчатся.

## Установка и использование

Скачайте ZIP из Releases. Закройте игру и скопируйте `WTTG2.SafeSkyCopy.dll` в `BepInEx/plugins`. Запустите игру снова. Для отката удалите эту DLL при закрытой игре.

F8 — панель копирования. Выделите текст и нажмите Ctrl+C либо используйте Copy all / Copy row / BSSID. Ctrl+Shift+C — копирование текущего вывода без панели. Закройте панель F8, чтобы вернуться к вводу команд. Не устанавливайте одновременно несовместимый Epic skyBREAK QoL 1.0.0.

В версии 1.0.1 отключение `EnableHotkeys` также закрывает панель и освобождает ввод терминала. Вывод обновляется и при переключении в другое приложение, чтобы панель очищалась после закрытия skyBREAK. Уже скопированный пользователем буфер обмена сохраняется.

## Исходники и сборка

Сборка требует локальные игровые библиотеки и BepInEx 5.4.23.5; они не включены в репозиторий.

```powershell
.\build.ps1 -GamePath "D:\Games\Welcome to the Game II"
```

## Проверка

Проверены сборка, 25 проверок текстовых функций и работа панели/буфера обмена в изолированной копии Unity. Полного игрового сеанса с ручной проверкой всех горячих клавиш не было.

Подробности исправления 1.0.1 и границы проверки — в [AUDIT.md](AUDIT.md).

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
